# Shakira Попутчики

Сайт для поиска попутчиков на концерт: водители из разных городов публикуют
свободные места в машине до арены и обратно, пассажиры бронируют места и
получают контакты водителя.

## Как это работает

- **Водитель** жмёт «Я водитель», указывает город, место посадки, направление
  (туда / обратно / туда и обратно), время, число мест, цену и контакты.
  После публикации он получает **секретную ссылку управления**: там видно, кто
  забронировал места (имя + телефон), можно отменить бронь или удалить поездку.
  Регистрация не нужна.
- **Пассажир** выбирает город и направление, открывает поездку и бронирует
  места. Контакты водителя показываются только после брони, в общем списке
  телефонов не видно.
- **Админ** выгружает все поездки и брони в Excel по ссылке
  `/api/export?key=ADMIN_KEY` (CSV с `;` и кириллицей, открывается в Excel
  двойным кликом).

## Хранение данных

Всё лежит в одном файле `data/rides.json` — без базы данных и регистраций.
Записи изменяются по очереди, файл пишется атомарно, поэтому одно место не
забронируют дважды. Бэкап — просто скопировать этот файл.

> Нужен сервер с постоянным диском (VPS, Railway, Render с диском и т.п.).
> На Vercel файловая система только для чтения: там файл придётся заменить
> на базу (например, Vercel KV / Postgres) — логика хранения целиком в
> `src/lib/db.ts`.

## Запуск

```bash
npm install
cp .env.example .env.local   # впишите название арены, дату и ADMIN_KEY
npm run dev                  # http://localhost:3000
```

Продакшен:

```bash
npm run build
npm start                    # порт можно задать через PORT=8080
```

## Настройки (`.env.local`)

| Переменная | Что это |
| --- | --- |
| `EVENT_ARTIST` | Имя артиста в шапке |
| `EVENT_TITLE` | Заголовок на главной |
| `EVENT_ARENA`, `EVENT_ARENA_ADDRESS` | Арена и адрес |
| `EVENT_DATE` | Дата и время концерта, `2026-11-14 20:00` |
| `ADMIN_KEY` | Ключ для выгрузки в Excel |
| `DATA_DIR` | Папка с `rides.json` (по умолчанию `data`) |

## Структура

- `src/app/page.tsx` — главная: фильтры и список поездок
- `src/app/rides/new` — форма водителя
- `src/app/rides/[id]` — поездка и бронирование
- `src/app/rides/[id]/manage` — страница водителя (по секретной ссылке)
- `src/app/api/export` — выгрузка в Excel
- `src/lib/db.ts` — чтение и запись `rides.json`
- `src/lib/actions.ts` — серверные действия (создание, бронь, отмена, удаление)
